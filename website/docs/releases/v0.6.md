# v0.6 Release Notes

`v0.6.1` was the prior stable line (superseded by [`v0.7`](./v0.7)). There is no standalone `v0.6.0` release —
the CHANGELOG shows `0.6.0` was integrated and validated internally, then shipped directly as `v0.6.1`.

## v0.6.1 — stabilization and positioning

### Stabilization

- Validated `0.6.0` integration against the full quality gate (`fmt`, `clippy`, workspace tests, docs build).
- Completed benchmark and smoke validation before the release cut.

### Documentation and positioning

- Repositioned the README and quickstart docs around low-ceremony adoption: copy commands first, add `@in`/`@out`
  for caching once you're ready.
- Promoted `--explain` and rollback-safe output promotion as the primary differentiators.
- Added a "Progressive Adoption" section to the migration guide for teams coming from Make/Just.

### Hygiene

- Renamed `examples/basic/pleasefile` to `examples/basic/broskifile` to remove legacy naming drift.

### CI / release finalization

- Fixed showcase CI packaging so `package_container` reliably resolves built artifacts in GitHub Actions.
- Fixed markdown lint spacing in quickstart docs (`MD032`) to keep `docs-ci` green.
